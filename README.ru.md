# GymCore — бесплатный дневник тренировок, без рекламы и подписок

**▶ Попробовать: [gymcore-omega.vercel.app](https://gymcore-omega.vercel.app/)** &nbsp;·&nbsp; [English version →](README.md)

Записывай подходы и суперсеты за пару секунд, следи за прогрессом в графиках, веди замеры тела и
собирай программы. Все функции — статистика, замеры, шаблоны и ИИ-тренер — открыты сразу после
регистрации. Без карты, без пробного периода, без рекламы и «премиум-режимов».

## Что внутри

| Возможность | Что делает |
| --- | --- |
| 🏋️ **Дневник тренировок** | Подходы, вес, повторы, суперсеты. Черновик не теряется, даже если случайно закрыть вкладку. |
| 📅 **История и календарь** | Все тренировки по дням — открыл день и видишь, что делал и с какими весами. |
| 📈 **Статистика прогресса** | Объём и динамика по упражнениям, графики по всей истории, а не по последним десяти тренировкам. |
| 📏 **Замеры тела** | Вес, грудь, талия, бицепс, бёдра, плечи — с историей изменений. |
| 🧩 **Шаблоны программ** | Собери программу один раз и запускай её в один клик. |
| 🤝 **Шеринг программ** | Отправь программу ссылкой — друг добавит её себе одним нажатием. |
| 📚 **312 упражнений с анатомией** | Готовая база плюс свои упражнения; видно, какие мышцы работают. |
| 🤖 **ИИ-тренер (по желанию)** | Подключается свой ключ Gemini / Claude / GPT — он хранится только в твоём браузере. |
| 📤 **Твои данные — твои** | Экспорт всей истории в JSON в любой момент. Никаких запертых данных. |
| 📱 **Сделано для телефона** | Открывается в браузере, ставится на домашний экран; тёмная тема и крупные кнопки для зала. |

Интерфейс на **русском и английском** (переключается в любой момент).

## Как это работает

1. **Создай аккаунт** — логин и пароль, 20 секунд.
2. **Добавь упражнения** — свои или установи готовую программу.
3. **Записывай подходы** прямо во время тренировки — черновик сохраняется по ходу.
4. **Смотри прогресс** — графики, замеры и история по дням.

## Частые вопросы

**Это бесплатно?** Да, полностью: дневник, статистика, замеры, шаблоны и ИИ-тренер — без подписок,
без рекламы и «премиум-режимов».

**Нужно вводить карту или оформлять пробный период?** Нет. Только логин и пароль: платёжные данные
не запрашиваются, доступ не ограничен по времени.

**Нужен ли интернет?** Да — данные хранятся в облаке, поэтому после входа они доступны с любого устройства.

**Куда попадают мои данные?** В защищённую базу, доступ к ним есть только у тебя. Всю историю можно
выгрузить в JSON в любой момент.

**Есть ли мобильное приложение?** GymCore — веб-приложение: открывается в браузере телефона и
добавляется на домашний экран.
