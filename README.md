# GymCore — Трекер Тренировок

**GymCore** — это современное веб-приложение для отслеживания тренировок, планирования программ и управления базой упражнений. Спроектировано как **PWA (Progressive Web App)** с интерфейсом в стиле iOS, обеспечивающим плавный и интуитивно понятный пользовательский опыт.

## ✨ Основные возможности

* **Тренировки в реальном времени**: Отслеживание весов, повторов и времени отдыха.
* **Умная система шаблонов**: Создание собственных программ тренировок или сохранение выполненной тренировки как шаблона одним кликом.
* **Поддержка Суперсетов**: Визуальное объединение упражнений в группы со специальной индикацией связей.
* **Глобальная база упражнений**: Каталог с детальной анатомией мышц и возможностью создания персональных упражнений.
* **Система модерации**: Пользователи могут отправлять свои упражнения на проверку, чтобы они стали доступны всем участникам сообщества.
* **Шеринг**: Генерация публичных ссылок для обмена упражнениями и программами.
* **Сохранение состояния**: Защита от потери данных — если вы случайно закроете вкладку или нажмете «назад», активная тренировка сохранится локально.

## 🛠 Технологический стек

### Frontend

* **Vanilla JavaScript**: Архитектура SPA (Single Page Application) без тяжелых фреймворков.
* **CSS3**: Использование Custom Properties для динамических тем (Светлая/Темная).
* **PWA**: Service Workers для работы в автономном режиме и установки на главный экран.
* **SortableJS**: Для удобной сортировки упражнений методом Drag-and-Drop.

### Backend (Node.js)

* **Express.js**: Быстрый и минималистичный веб-фреймворк.
* **PostgreSQL**: Реляционная база данных для надежного хранения данных.
* **JWT (JSON Web Tokens)**: Безопасная авторизация пользователей.
* **Bcrypt**: Хэширование паролей.

## 🛡 Безопасность и Надежность

Приложение подготовлено к работе в Production:

* **SQL Транзакции**: Гарантируют целостность данных при сохранении сложных структур (Тренировка -> Упражнения -> Подходы).
* **Helmet**: Защита заголовков HTTP.
* **Express Rate Limit**: Защита от DDoS-атак и брутфорса паролей.
* **CORS**: Настроенная политика кросс-доменных запросов.
* **Input Validation**: Экранирование HTML на фронтенде для защиты от XSS.

## 📦 Установка и запуск

### 1. Требования

* Node.js (версия 16 или выше)
* PostgreSQL

### 2. Клонирование и установка зависимостей

```bash
git clone https://github.com/niksgawrilenko/gymcore.git
cd gymcore/backend
npm install

```

### 3. Настройка базы данных

1. Создайте базу данных в PostgreSQL (например, `gymcore`).
2. В папке `backend` создайте файл `.env` на основе примера:
```env
PORT=5000
DB_USER=your_user
DB_PASSWORD=your_password
DB_NAME=gymcore
DB_HOST=localhost
DB_PORT=5432
JWT_SECRET=your_very_long_secret_string

```



### 4. Запуск проекта

**Запуск бэкенда (из папки backend):**

```bash
npm run dev

```

**Запуск фронтенда:**
Откройте папку `frontend` через любой локальный сервер (например, расширение Live Server в VS Code).
