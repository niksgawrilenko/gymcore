# GymCore — Project Brief

> Фундамент. Меняется редко. Если меняется — сначала здесь.

## Что это

Одностраничное веб-приложение для записи и анализа тренировок.
Аккаунт у каждого пользователя свой; есть шеринг (ссылки `share_id`) и админ-модерация публичных упражнений/шаблонов.

Это **не** старая Express+PWA версия — проект переписан на Next.js App Router (см. `progress.md`).

## Ядро продукта

| Домен | Что умеет |
| --- | --- |
| Тренировка | упражнения по порядку, подходы (вес × повторы), суперсеты, замена/сворачивание упражнений и подходов, черновик в `localStorage` |
| База упражнений | свои + публичные, мышцы/анатомия, медиа в Cloudinary, шаринг по `share_id`, импорт чужого упражнения |
| Шаблоны программ | редактор (dnd-kit), генерация подходов, сохранение тренировки как шаблона, шаринг |
| История | календарь по дням, детальная страница тренировки |
| Статистика | объёмы, прогресс по упражнению, графики (chart.js + react-chartjs-2) |
| Замеры тела | форма + история замеров |
| ИИ-тренер | провайдер-агностик чат (`/ai`) + разбор в профиле; Gemini / OpenAI / Claude |
| Аккаунт | вход/регистрация, настройки, экспорт данных (`/api/export`) |

## Границы (scope)

- Мультиязычность **отсутствует** → внедряется сейчас: en (primary) + ru. План — `docs/i18n-plan.md`.
- Отдельного API-сервера нет: всё через Server Actions и серверные компоненты. Исключение — `src/app/api/export/route.ts`.
- Мобильного приложения нет; UI адаптивный. `src/app/manifest.ts` — для установки как PWA.

## Инварианты (нарушение = баг)

1. **Владелец данных.** Каждая Server Action проверяет владельца ресурса; чужие данные недоступны даже при знании id.
2. **Схема БД** ведётся в `db/schema.sql` + `db/indexes.sql` (идемпотентно). `drizzle-kit push` на проде запрещён (README).
3. **Даты** форматируются в таймзоне устройства (cookie `tz`), не сервера.
4. **Черновик тренировки** живёт в `localStorage` и переживает перезагрузку; на сервер уходит только по «Сохранить».
5. **Медиа** грузится из браузера прямо в Cloudinary по подписи, выданной сервером.
